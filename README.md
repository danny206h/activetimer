# Jimothy's Workout Timer

A single-page workout interval timer with configurable work duration, rest duration, and round count.

## Features

- Original Jimothy-inspired raccoon logo
- 10-second warm-up before round 1
- 3, 2, 1 warm-up countdown before the first work round
- Large phase-colored countdown display
- Work/rest round tracking
- Sound on/off toggle
- Volume slider up to 300%
- Countdown cues for the final seconds of work and recovery
- Bell cue for round start
- Loud four-ring bell cue when each non-final work rep ends
- Final workout-complete theme with loud bells and an 8-bit platformer-style victory dance
- Final work round skips recovery and goes straight to complete

Open `index.html` in a browser to use it.
